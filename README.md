# Typstcontainer

> A template for editing typst documentes locally without having to install anything else 

Working with typst documents online is as easy as pie, just open up the [online editor](https://typst.app) and start typing away. For some cases you may want to work offline though, in this case it is necessary to install the typst compiler locally. To make this process easier, you can use this repository as a template and start working in the dev-container included here. This will make sure:

- You don't have to install any tools or programms.
- All features of Typst are already included.
- Editing can happen completly local.
